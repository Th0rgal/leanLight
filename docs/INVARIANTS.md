# Invariants of the light client

Rows 25a to 25l of leanKohakuDesktop's (private) `spec/INVARIANTS.md` at `7a491530` (2026-10-29), copied verbatim: the invariants leanLight's code and proofs carry. The comments cite them by id (`25c` and so on). Their names are the wallet's modules (`LkdLc.X` here is `LeanLight.X`, `LkdProofs.Lc.X` is `LeanLightProofs.X`, namespace `Lkd` is `LeanLight`); the wallet's rows past 25l (its planner, wire frames, caches, UI) are not leanLight's and are left out. A row's Status rose only with a theorem in the wallet's audit; leanLight's own audit (`scripts/check-axioms.sh`) checks every constant.
